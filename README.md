# Gatitos desde una API · Taller web para NASA Space Apps Challenge 2025

Primer ejercicio del entrenamiento que di a los estudiantes de la PUCE Sede Esmeraldas (PUCESE) para el **NASA International Space Apps Challenge 2025**: un solo `index.html` que consume una API pública con `fetch` y pinta el resultado en la página.

Es el mismo patrón que luego usan los equipos con los datos abiertos de la NASA: **pedir datos → leer el JSON → mostrarlo**.

🎥 [Sesión de entrenamiento](https://youtu.be/JQhSS41FXxk) · 🌐 [Ver en vivo](https://kevingo710.github.io/example-pucese-one/) · 📱 Taller móvil: [example-expo](https://github.com/kevingo710/example-expo)

## Qué se aprende

- `async` / `await` y `fetch` contra una API REST ([The Cat API](https://thecatapi.com/))
- Leer una respuesta JSON y usarla en el DOM
- Del gatito a la NASA: cambia la URL por [APOD](https://api.nasa.gov/) (`https://api.nasa.gov/planetary/apod?api_key=DEMO_KEY`) y muestra `data.url` y `data.title`

## Ejecutarlo

Abre `index.html` en el navegador. No necesita instalar nada.
